# Portfolio Website 👨‍💻

A fully responsive, visually appealing personal portfolio website designed to showcase skills, projects, and professional background. This project acts as a digital resume and a central hub for my work as a Python Developer and AI Engineer.

## 🚀 Overview

This repository contains the source code for a personal portfolio website. It features a modern design with smooth animations, interactive elements, and a clean user interface. The site highlights my journey as a developer, the services I offer, and the projects I've built.

## ✨ Features

-   **Responsive Design:** Fully adaptable to different screen sizes (Mobile, Tablet, Desktop).
-   **Interactive UI:**
    -   **Typed Text Animation:** Dynamic text introduction using `Typed.js`.
    -   **Scroll Animations:** Elements fade in and slide as you scroll using `ScrollReveal`.
    -   **Sticky Navigation:** The navigation bar sticks to the top for easy access.
    -   **Active Link Highlighting:** Navigation links update based on the current scroll position.
-   **Dark Theme Aesthetic:** A sleek, developer-centric dark, neon-style color scheme.
-   **Sections included:**
    -   **Home:** Introduction and quick resume access.
    -   **About:** Professional background and skills overview.
    -   **Services:** Details about technical expertise (Frontend, Software Dev, etc.).
    -   **Projects:** A gallery of recent work with links to live demos or code.
    -   **Contact:** A functional form layout for getting in touch.

## 🛠️ Technologies Used

-   **HTML5:** Semantic markup for structure.
-   **CSS3:** Custom styling, Flexbox for layout, and responsive media queries.
-   **JavaScript (ES6):** Logic for navigation, scrolling, and interactivity.
-   **External Libraries:**
    -   [Boxicons](https://boxicons.com/): For vector icons.
    -   [ScrollReveal](https://scrollrevealjs.org/): For scroll animations.
    -   [Typed.js](https://github.com/mattboldt/typed.js/): For the typing text effect.

## 📂 Project Structure

```bash
Portfolio-main/
├── images/           # Contains all image assets (profile pics, project thumbnails)
├── index.html        # Main HTML structure
├── style.css         # All styling and responsive design rules
├── script.js         # JavaScript for animations and interactivity
└── README.md         # Project documentation
```

## 🚀 How to Run Locally

Since this is a static website, you don't need to install complex dependencies or run a build server.

1.  **Clone the repository** (or download the ZIP):
    ```bash
    git clone https://github.com/your-username/portfolio.git
    ```
2.  **Navigate to the project folder**.
3.  **Open `index.html`** in your web browser (Chrome, Firefox, Edge, etc.).

*Tip: For the best experience, use a simple local server extension like "Live Server" in VS Code.*

## 🎨 Customization

To customize this portfolio for yourself:
1.  **Update Content:** Edit `index.html` to change the name, "About Me" text, services, and contact info.
2.  **Change Images:** Replace images in the `images/` folder with your own (ensure filenames match or update `src` attributes in HTML).
3.  **Colors:** Modify the color variables (if any) or specific styles in `style.css` to match your preferred palette.
4.  **Links:** Update the social media `href` links and project URLs in `index.html`.
